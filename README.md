# 山口県 地価公示マップ

国土交通省「国土数値情報（KSJ）地価公示データ（L01）」を元にした、山口県内の地価公示（令和7年/2025年）Webマップ。全304地点。各地点をクリックすると1983年（昭和58年）〜2025年（令和7年）の価格推移を表示します。

**公開URL**：https://kabaran.github.io/yamaguchi-chika-kouji-map/

## データ出典

- 国土交通省 国土数値情報ダウンロードサイト「地価公示データ（L01）」
  https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L01-2025.html
- 出典元：国土交通省
